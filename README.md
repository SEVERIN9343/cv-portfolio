# Portfolio numérique — OGAH Sévérin

Portfolio professionnel présentant mes compétences et réalisations en **SEO, WordPress, développement web et Web Performance**.

Ce projet a été conçu pour mettre en avant une approche à la fois **SEO et technique** : de l’analyse d’un site et de sa visibilité organique jusqu’à la mise en œuvre directe d’optimisations sur WordPress.

---

## À propos

Je m'intéresse particulièrement au référencement naturel et à l'optimisation de sites web, avec des compétences complémentaires en développement **WordPress, PHP, HTML, CSS et JavaScript**.

Cette double compétence me permet d'aborder un projet SEO au-delà de l'analyse : audit technique, recherche de mots-clés, optimisation On-Page, performance web, puis intervention sur le site lorsque des corrections techniques sont nécessaires.

---

### Étude de cas — VPCE

Une étude de cas complète est consacrée au projet **Vect Pest Control Expert (VPCE)**.

Le projet présente une démarche SEO menée de l'audit initial jusqu'à l'analyse des résultats :

1. audit du site ;
2. benchmark concurrentiel ;
3. recherche de mots-clés ;
4. optimisation SEO technique ;
5. optimisation SEO On-Page ;
6. optimisation WordPress et Web Performance ;
7. contrôle technique après intervention ;
8. analyse des résultats.

Le portfolio permet également de consulter le **rapport SEO complet au format PDF**.
